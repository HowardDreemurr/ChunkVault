# Internationalization (i18n)

The wizard speaks 9 languages. The CLI is English-only (operator-target,
not end-user-target). Adding a new locale is a single JSON file plus a one-
line list update.

## Supported locales

| Code      | Language                |
| ---       | ---                     |
| `en`      | English                 |
| `zh-CN`   | Simplified Chinese      |
| `zh-TW`   | Traditional Chinese     |
| `ja`      | Japanese                |
| `ko`      | Korean                  |
| `de`      | German                  |
| `fr`      | French                  |
| `es`      | Spanish                 |
| `ru`      | Russian                 |

The README is also available in
[Simplified Chinese](https://github.com/howardcui/chunkvault/blob/main/README.zh-CN.md);
other languages live only in the wizard.

## How it works

Locale data lives at `chunkvault/wizard/locales/<bcp47>.json`:

```text
chunkvault/wizard/locales/
├── en.json
├── zh-CN.json
├── zh-TW.json
├── ja.json
├── ko.json
├── de.json
├── fr.json
├── es.json
└── ru.json
```

Each file is a flat JSON object `{key: translated_string}`. Flow code calls
`t("key.path", **fmt_kwargs)`:

```python
from chunkvault.wizard.i18n import t

print(t("menu.snapshot.title"))
print(t("flow.snapshot.done", count=42, vault="F:/Vaults/EX-Server"))
```

`t()` looks up the key in the active locale, falling back to English if the
key is missing. Format substitution is plain `str.format(**kwargs)`.

## Selecting a locale

Resolution order (first hit wins):

1. Saved choice in `~/.chunkvault/config.json`.
2. `LANG` / `LC_ALL` / `LC_MESSAGES` env vars (POSIX-style; chunkvault
   normalizes `zh_CN.UTF-8` → `zh-CN`, etc.).
3. English (`en`).

To change at runtime:

- **From the wizard:** Settings ▸ Language. Takes effect immediately.
- **From the registry directly:** edit
  `~/.chunkvault/config.json`'s `"locale"` key.
- **Per-launch:** set `LANG=ja_JP.UTF-8` (or any supported tag) before
  running `chunkvault`.

## Adding a new locale

1. Create `chunkvault/wizard/locales/<bcp47>.json`. The simplest start: copy
   `en.json` and translate the values in place. Keys must stay literal.
2. Verify by running `chunkvault` with `LANG=<bcp47>` set. Missing keys
   fall back to English visibly.
3. Add a test (optional but encouraged): `tests/wizard/test_i18n.py`
   already round-trips every locale's keys against `en.json`.

The locale loader auto-discovers any `.json` file in the locales directory
on launch — no list to update.

## Translation guidelines

- **Don't translate file paths, command names, or environment variables**
  — `chunkvault snapshot ...` stays English everywhere.
- **Keep `{placeholders}` exactly as-is** — they're substituted at runtime.
- **Match register and tone** — the wizard is friendly-but-direct;
  translations should feel native, not literally back-translated from
  English.
- **Test in your terminal** — some glyphs (CJK punctuation, RTL marks) can
  break the alignment of `rich.Table`s. If something looks off, file an
  issue with a screenshot.

## CLI is English-only

The CLI's `--help`, error messages, and progress phase labels are not
localized. Rationale: the CLI is for operators (you, scripts, CI), and a
mixed-locale shell session is more confusing than an English one. Localize
the wizard instead — that's where end-user-facing text lives.
